# Routing

Scout is enabled for proven read-only assignments; editor is enabled only through staged promotion.
Scout requires the fresh-project route, plan/sandbox mode and the absolute
added workspace. Editor state changes cannot bypass staged promotion: exact
base and owned paths, disposable workspace, complete scope audit, authoritative
state recheck, whole-candidate promotion and independent Codex inspection.
An unowned staging change rejects the whole candidate and uses V2 fallback.

Prefer scout for file/symbol/call-path maps, affected-test candidates,
reference/removal/stale-doc searches, dependency and ownership overlap,
omission sweeps, supplied local CI/evidence clustering and dependency-ready
next-issue preparation during immutable waits. Unknown defects still belong
to the Astra-medium diagnostician; Flash only clusters supplied evidence.

Editor is limited to explicitly bounded, mechanically verifiable O-tier work:
repetitive UI wiring, fixed-interface boilerplate, documentation sync after
decisions are final, narrow straightforward adapters, fixture skeletons with
defined expected behavior and mechanical refactors. Codex defines behavior
and independently executes tests. No test sufficiency decisions by Flash.

Use normal V2 for architecture, ambiguous defects, finance, PIT, replay,
provenance, persistence, migrations, concurrency, security, programme control,
broker/execution authority, release/supply chain, substantial test design or
C-tier work. Formal reviewer/risk/release gates are V2 only. Performance work
retains benchmark_guard and performance_refactorer; Flash may only map or
summarize. Never invent assignments to consume quota.
