## Legend
- **Verdict**: CONF = confirmed by reading the code at the cited lines; CONF-R = confirmed and reproduced; PART = partly true (see note); NOT = not a bug / rejected (reason given); DUP = duplicate of another id.
- **Fix**: the smallest DRY/KISS change. "→ H:x" = uses shared helper x (section Shared helpers).
- **Train**: the batch it is fixed in (section Trains). One worktree + one writer per train; one Sol review per train.
- **Effort**: S ≤ 20 lines, M ≤ 80 lines, L larger.
- **Status**: open / fixed `<sha>` / rejected.
