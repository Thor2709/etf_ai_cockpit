# Source Archives

This folder contains extracted reference archives supplied with the project:

- `timesfm-2.0.1` - TimesFM 2.5 source package, examples and references.
- `toto-toto-models-v1.0.0` - Toto 2.0 source packages, benchmark material and examples.

The original ZIP files are also copied here for provenance:

- `timesfm-2.0.1.zip`
- `toto-toto-models-v1.0.0.zip`

These folders and ZIP files are not imported by the app at startup. They are kept as local reference material for building or installing optional live model runtimes later. Model weights should live under `models/timesfm/` and `models/toto/`.

See `MODEL_ARCHIVE_MANIFEST.md` for checksums and the current installation status.
